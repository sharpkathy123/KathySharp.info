iPad + Safari Web Development in GitHub Codespaces

A simple, AI-generated guide to editing HTML/CSS pages on an iPad without dealing with broken extension windows, touch drag-and-drop issues, or crashed preview panes.

Why Avoid the "Live Preview" Extension on iPad?

VS Code's embedded Live Preview extension relies on internal browser frames that frequently crash on iPadOS. This locks up the editor screen, overlaps code text, and spawns stuck background server processes ("zombie ports").

Step 1: Clean Up Stuck Background Processes

If your editor was previously stuck or showing multiple unused ports, run this quick command to reset everything:

  1. Open the Terminal panel at the bottom of Codespaces.
  2. Type the following command and press Return: 
    pkill -f node
  3. Open the Extensions tab on the left sidebar, find Live Preview, and tap Uninstall.

Step 2: Start the Lightweight Python Web Server

Instead of relying on heavy extensions, use Python's built-in web server directly in your terminal:

  1. In the Terminal panel, type: 
    python3 -m http.server 8000
  2. Press Return. You will see a notification confirming the server is running on port 8000.

Step 3: Preview Pages in a Dedicated Safari Tab

  1. Tap the Ports tab at the bottom of the editor window.
  2. Find Port 8000 in the list.
  3. Tap the Globe icon (or tap and hold port 8000 and choose Open in External Browser).
  4. Safari will open your live web page in a new full browser tab.
Recommended iPad Layout: Use iPadOS Split View to place Safari side-by-side with your Codespace window.

To set it up: Tap the three dots (•••) at the top center of your iPad screen → select Split View → pick your Safari preview window. Now you can edit code on the left, save, and simply tap refresh on the right!

Step 4: Useful iPad Keyboard Shortcuts

  • Cmd + S — Save your HTML/CSS file edits.
  • Cmd + Shift + P — Open Command Palette (for quick settings).
  • Cmd + B — Hide/Show the left file sidebar for maximum screen space.
  • Cmd + J — Hide/Show the bottom Terminal/Ports panel.
  • Ctrl + C (in terminal) — Stop the Python web server when done.
