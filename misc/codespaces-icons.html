GitHub Codespaces Icon Cheat Sheet

AI-generated quick visual guide to icons, indicators, and status symbols in VS Code & Codespaces

1. Activity Bar (Far-Left Navigation Sidebar)
Icon Name Primary Function & Action
📄 Explorer Browse workspace file tree, open editors, and project directories.
🔍 Search Search and replace text globally across all files in your project.
🌿 Source Control Manage Git changes, stage modified files, commit, and push/pull to GitHub.
🪲 Run & Debug Launch debug configurations, set breakpoints, and view execution call stacks.
🧩 Extensions Search, install, or configure extensions, themes, and language helpers.
⚙️ Settings Access editor preferences, keyboard shortcuts, color themes, and user settings.
2. Status Bar (Bottom Panel Controls)
Icon Name / Indicator Meaning & Interaction
>< Remote Indicator Active Codespace session. Tap/click to stop container, rebuild, or change machine.
📡 Forwarded Ports Opens the Ports tab to preview local web servers (localhost) in browser.
🔀 Git Branch Displays active Git branch name. Tap to switch branches or checkout a new one.
🔄 Syncing / Building Container background task running (pulling commits, installing dependencies, building).
🔌 Disconnected Connection to remote dev container lost or timed out. Tap to reconnect.
3. Editor Header & Tab Actions (Top-Right)
Icon Name Function
📑 Split Editor Splits the active file or editor into two side-by-side editing panes.
▶️ Run Code Executes the active script file directly inside the integrated terminal.
📖 Markdown Preview Toggles side-by-side rendered HTML preview for .md documents.
... More Actions Opens contextual overflow menu options for the current active editor tab or panel.
4. Source Control Status Badges
Symbol Git State Description
M Modified File exists in Git repository but has unstaged changes.
U Untracked Newly created file that is not yet tracked or committed in Git.
A Added File has been staged (git add) and is ready for the next commit.
D Deleted File was removed or deleted from the local workspace.
Pro Tip for iPad Users: Open the Command Palette anytime using Cmd + Shift + P (or Ctrl + Shift + P) to trigger any command by name without searching for its icon.
