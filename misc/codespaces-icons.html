GitHub Codespaces: Complete Interface & Icon Reference

An exhaustive visual guide mapping out every top toolbar icon, sidebar panel badge, editor tab control, and bottom status bar indicator in the GitHub Codespaces / VS Code web environment using official Codicons.

1. Top Header & Navigation Bars (Lines 1 & 2)

Controls located at the very top of the editor and directly above the code file tabs.

Icon Name Function & Description
Main Menu (Hamburger) Opens top-level VS Code menus (File, Edit, Selection, View, Go, Run, Terminal, Help). Essential on iPad when native menu bars are hidden.
Navigate Back / Forward Jumps backward or forward through your recent cursor positions or file history across the workspace.
Split Editor Right Splits the active editor pane horizontally into side-by-side columns.
Show Live Preview Renders an internal webview preview of the active HTML document.
Open in External Browser Launches the rendered web preview or forwarded port in a full Safari tab outside the editor frame.
More Actions / Editor Options Reveals contextual actions like pin tab, clear split, lock editor group, or show file breadcrumbs.
Close Tab Closes the current file tab. Unsaved changes will prompt a save warning unless auto-save is active.
M / U Git File Badges M = Modified (changes made since last commit). U = Untracked (new file not yet added to Git).
Unsaved Changes Indicator Appears on a tab title when changes exist in memory that have not yet been written to disk.

2. Left Primary Sidebar Navigation

The primary tool selector icons running along the far left edge of the screen.

Icon Name Function & Description
Explorer Shows your complete project folder tree, open editors, and project files.
Search Global search and replace across all files in your repository (Cmd+Shift+F).
Source Control (Git) Tracks changed files, staging, commit message input, and Push/Pull sync actions. Displays a numeric badge of pending changes.
Run & Debug Configures launch scripts, breakpoints, call stacks, and interactive debugging environments.
Extensions Browse, install, disable, or configure VS Code marketplace plugins (e.g., Python, Prettier, Themes).
Accounts & Settings Manage GitHub account sync, keybindings, color themes, settings sync, and user preferences.

3. Bottom Status Bar (Very Bottom Line)

Real-time environment stats, Git branch details, port mappings, and encoding indicators running along the bottom blue/purple bar.

Icon Name Function & Description
Codespaces Remote Indicator Shows active connection status to your cloud container. Tapping opens remote options (Rebuild Container, Stop Codespace).
main* Git Branch & Status Displays current working branch (e.g., main). Asterisk indicates uncommitted local changes. Tapping opens branch selector.
Synchronize Changes Shows incoming ($\downarrow$) and outgoing ($\uparrow$) commits relative to GitHub. Tapping triggers a Git Pull/Push.
0 0 Problems Panel Indicator Displays total syntax errors and warnings detected in workspace files. Tapping opens Problems panel.
Ports Forwarding Status Displays active forwarded web ports (e.g., port 8000 for Python HTTP server). Tapping opens the Ports panel.
Ln 24, Col 12 Cursor Position Shows current active line number and character column. Tapping opens "Go to Line" prompt.
Spaces: 2 Indentation Rules Displays tab size or indentation mode (Spaces vs. Tabs). Tapping lets you reformat spacing or convert tabs.
UTF-8 File Encoding Displays character set encoding for the active file. Tapping allows switching encoding modes.
/ HTML Language Mode Identifies file type syntax highlighting and IntelliSense grammar rules. Tapping lets you override mode manually.
Notifications Bell icon showing system alerts, extension messages, or background terminal tasks. Numeric badge indicates unread alerts.

4. Lower Terminal & Drawer Tabs

Tabs located in the collapsible bottom drawer (toggleable via Cmd+J).

Icon Tab Name Function & Description
Terminal Command-line interface to your Codespace container. Used to run bash commands, Python servers, or Git scripts.
Ports Lists active web application ports, local addresses, visibility (Private/Public), and preview launch buttons.
Output Displays background extension logs, language server diagnostics, and task execution output.
Problems Aggregates syntax errors, missing CSS tags, broken code rules, and linting issues in one scannable list.
